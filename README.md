# Calculadora de Renda Fixa

Projeto simples de calculadora de investimentos em renda fixa, construído com HTML, CSS e JavaScript.

## O que o projeto faz

- Simula investimentos em CDB, LCI/LCA, Tesouro e Poupança
- Suporta rentabilidade pré-fixada e pós-fixada (CDI/SELIC)
- Calcula aporte inicial, aporte mensal e prazo em dias/meses/anos
- Aplica IOF regressivo para resgates antes de 30 dias
- Aplica IR regressivo conforme prazo da renda fixa
- Oferece até 5 simulações simultâneas
- Permite comparar resultados entre cenários
- Gera gráficos de evolução e composição com Chart.js
- Inclui tema escuro com botão de alternância

## Observações

Este projeto foi desenvolvido com auxílio do Claude AI para fins de estudo, aprendizado e experimentação.

As simulações apresentadas possuem caráter exclusivamente educacional e informativo. O projeto não constitui recomendação de investimento, consultoria financeira ou qualquer tipo de orientação profissional.

Os cálculos podem apresentar divergências, imprecisões ou erros, especialmente em relação a regras tributárias, índices econômicos e rentabilidade real de produtos financeiros.

Este não é um sistema financeiro oficial nem uma aplicação destinada ao uso comercial ou tomada de decisão financeira real.

## Como executar

Basta abrir o arquivo `index.html` em qualquer navegador.
